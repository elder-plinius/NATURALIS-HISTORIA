# Corpus provenance

The reader data in `public/corpus/` is generated by `scripts/build-corpus.py`
from these complete public sources:

- Latin: Pliny the Elder, *Naturalis Historia*, Karl Friedrich Theodor
  Mayhoff, ed. (Teubner, 1906), Perseus Digital Library TEI edition:
  release `0.0.28400408640`, commit
  `53d95ef61007fcafa4b6c4b43399acd2d114c9e2`, SHA-256
  `e8ad7ddbb99847f3f1985f2fd0ef93a359ff974d97a14b3915e6998768b7b737`.
  The immutable source URL is recorded in the generated corpus manifest.
- English: John Bostock and H. T. Riley, trans., *The Natural History of
  Pliny* (London, 1855-57), the six proofread Project Gutenberg volumes:
  ebooks `57493`, `60230`, `59131`, `61113`, `60688`, and `62704`.

The downloaded XML and HTML files are intentionally ignored by Git. The build
fails before parsing unless all seven primary source hashes and the Latin
comparator hash match their pinned receipts. Re-fetch them at the paths
expected by the build script, then run:

```sh
python3 scripts/build-corpus.py
```

The script produces a documented reading text: it removes TEI critical
apparatus, translation footnotes, and page furniture while retaining the
edited Latin base text and the main translation prose. The reviewable ledger
in `corrections.json` records eight confirmed Latin transcription corrections
and all 27 `for/read` entries in the Gutenberg Volume I Appendix. Twenty-five
Appendix corrections affect emitted reader prose; two concern deliberately
excluded editorial or footnote material and remain recorded with that scope.
The public generated ledger also exposes all 26 extraction repairs for
numbered print-line splits and demonstrable apparatus fragments. Every emitted
replacement is scoped to a book and unit and required to occur exactly once.
Ambiguous plain hyphen-space sequences remain as transmitted. Printer errata
are kept distinct from any future modern editorial emendation.

The bilingual-unit key is each `<div subtype="chapter">/@n`; the TEI's CTS
declaration calls these divisions **chapters**. Smaller Mayhoff
`<milestone unit="section">` markers occur inside them, are preserved as exact
metadata (including uncertain source values), and are not separate navigation
units. The reader joins the editions at the numbered Latin chapter divisions,
using the translation's parenthetical alternate numbers. This is historical
chapter-level alignment; Bostock-Riley is not a line-by-line translation of
the Mayhoff text. Its ordinary `CHAP.`
headings (the Bostock-Riley/Hardouin hierarchy) remain searchable metadata. A
separate correction ledger restores omitted or erroneous printed boundary
numbers only where the adjacent heading and Latin opening make the join
unambiguous; source-order assertions prevent a bad number from silently
reordering prose.

The build verifies all 37 books and writes one content-hashed, immutable JSON
file per book plus a revalidated `manifest.json` and `corrections.json`. The
result contains one Book I dedication/index unit and
1,064 numbered Perseus TEI chapter divisions: 1,065 bilingual reading units in
all. Fifteen Latin prefaces are folded into the first numbered chapter of their
books. The English edition's finer chapter hierarchy is retained as metadata,
so all of its headings are visible in the index and searchable even when
several occur within one Latin chapter. Its book-end summaries and author lists
are also retained, but separately from the facing translation. The Latin
critical apparatus and English scholarly footnotes remain outside this reading
edition.
