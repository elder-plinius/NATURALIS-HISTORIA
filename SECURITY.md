# Security policy

## Supported version

Security fixes target the latest `main` branch. This policy does not represent
a public deployment as active; support for any future authorized deployment
will be documented explicitly.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability involving credentials,
authentication, private data, or a deploy bypass. Use GitHub's private
vulnerability reporting for
`elder-plinius/naturalis-historia`, or contact the repository owner privately.

Include the affected URL or commit, reproduction steps, impact, and any safe
mitigation you tested. Do not access other readers' data or publish a working
exploit before a fix is available.

The maintainers will acknowledge a complete report as soon as practical and
will coordinate disclosure after the affected code is patched and, when
applicable, an authorized deployment is updated.
